# AI Website Chatbot Qualifier — Interactive Demo

An interactive, scripted-simulation demo of an embed-style AI chat widget on a
fictional roofing company's website ("BrightPeak Roofing Co.") that qualifies a
visitor and books a free inspection — reaching the payoff in under 90 seconds.

**Live demo:** https://ai-chatbot-qualifier-mr-bilal-alis-projects.vercel.app

**What it shows:** embed-style website chat widget → visitor qualification
(service need → urgency → timeline → name) → inspection slot booking → lead
summary card with "qualified & booked in N seconds" → confirmation-text preview
→ booking CTA.

**Honest framing:** clearly labeled throughout as a *scripted simulation* of a
fictional business. It places no real calls, sends no real SMS, and books no
real appointments. No real client names, numbers, or results are used or
implied.
